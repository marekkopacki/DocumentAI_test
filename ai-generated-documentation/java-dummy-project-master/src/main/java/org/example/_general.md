## General Documentation for example package
Description: The example package consists of two main classes, `Client` and `Service`, which work together to generate personalized greetings based on the length of the input name. The `Client` class interacts with a `Service` object to determine if the name length is even or odd and returns the greeting in uppercase or original case accordingly. The `Service` class provides two methods: `isEven` to check if an integer is even, and `highComplexityMethod` to print statements based on the signs of three input integers.
