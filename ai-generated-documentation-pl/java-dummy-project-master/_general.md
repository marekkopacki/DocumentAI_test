## Dokumentacja ogólna dla pakietu java-dummy-project-master
Opis wygenerowany na podstawie dostarczonych plików Markdown. Zbierz wszystkie opisy z tych plików. Pakiet `java-dummy-project-master` to projekt Java o nazwie "dummy-java-project" z grupy "org.example". Wykorzystuje Maven jako narzędzie budujące, z dobrze ustrukturyzowanym plikiem `pom.xml`, który konfiguruje zależności projektu, ustawienia kompilatora i framework testowy. Projekt wykorzystuje JUnit 5 wraz z bibliotekami Mockito i AssertJ do celów testowych.
